# **Challenge**

## **I Believe I Can Fly !**

Tu vas pouvoir t'exercer à la création et l'implémentation d'une interface, en premier [**fais un Fork du dépôt suivant**](https://github.com/WildCodeSchool/quest-java-poo3) puis clone-le en local.

> Pense bien à faire un Fork, sinon tu ne pourras rien pousser !

Exemple de résultat lors de l'exécution de `Nature` :

```
Hawkeye takes off in the sky.
Hawkeye flies upward, altitude: 120
Hawkeye flies upward, altitude: 150
glides into the air.
Hawkeye flies downward, altitude: 10
Hawkeye is too high, it can't land.
Hawkeye flies downward, altitude: 1
Hawkeye lands on the ground.

```

## **Critères de validation**

- [x] Le dépôt *GitHub* contient bien le fichier `Fly.java`
- [x] Les classes et interfaces respectent les conventions de la POO : attributs privés, utilisation du mot-clef *this*, *getters* et *setters* nommés correctement
- [x] La classe `Eagle` implémente l'interface `Fly`
- [x] La classe `Nature` contient l'appel des méthodes d'une instance de `Eagle`
- [x] La classe `Nature` se compile sans erreur et affiche dans le terminal un résultat proche de celui présenté précédemment
